# `@agent-context/efficiency`

Internal deterministic token accounting, scoring, recommendation, and reporting for Agent Context
Linter. G09 report APIs are available at the package root and the focused `./report` subpath. G03
exposes both single-DAG accounting and an issued, bounded multi-entry composer for effective
contexts containing several top-level instruction documents.

Published closed schemas cover tokenizer identity, score specification, scores, recommendations,
single reports, and compatible comparisons. See the
[report API](../../docs/api/context-efficiency-reports.md),
[developer contract](../../docs/development/context-efficiency-reports.md), and
[security boundary](../../docs/security/context-efficiency-reports.md).
