# Changelog

Important repository-wide changes are recorded here. Published package release notes are generated
by Changesets in each public package's `CHANGELOG.md`.

The format follows the conventional categories Added, Changed, Deprecated, Removed, Fixed, and
Security, and versions follow Semantic Versioning.

## 1.0.0

### Added

- Adopted Apache License 2.0 project licensing and a deterministic Changesets release process.
- The first stable Agent Context Linter release provides the deterministic offline linter, standards
  inspection and local refresh tooling, efficiency reports, and documented public CLI/API contracts.

### Removed

- Experimental empirical benchmark runners, benchmark fixtures, and client-sandbox observation
  tooling are not included in the `1.0.0` release.

Apache-2.0 distribution applies to the release and all distributed packages.
