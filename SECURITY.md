# Security Policy

## Supported versions

The `1.0.0` release is supported on the current `main` line; older snapshots and local builds do not
receive fixes.

| Version                          | Security fixes |
| -------------------------------- | -------------- |
| `1.0.0` current release line     | Yes            |
| Older snapshots and local builds | No             |

## Report a vulnerability

Send a private report to <jakub.niezgoda@areaautomation.com> with the subject
`Agent Context Linter security report`. Do not open a public issue. Include the affected version or
commit, impact, prerequisites, minimal reproduction, and any suggested mitigation. Remove secrets
and private-repository data.

The project will acknowledge receipt on a best-effort basis, validate the report, coordinate a fix
and disclosure when warranted, and credit reporters who request credit. No response or remediation
SLA is promised. If this channel cannot be used safely, send only a request to establish an
alternate private channel; do not send vulnerability details publicly.

Maintainers follow [`docs/security/security-response.md`](docs/security/security-response.md).
