# Support

The Agent Context Linter `1.0.0` release is supported under the runtime, operating-system, and
compatibility windows listed in [`docs/support.md`](docs/support.md).

For usage questions and reproducible defect reports, use the repository's normal project discussion
or issue channel when one is available. Until a public repository URL is documented, email
<jakub.niezgoda@areaautomation.com>. Include the linter version, Node.js and pnpm versions,
operating system, exact command, sanitized configuration, expected result, and minimal reproduction.
Never send secrets or grant access to a private repository.

Security reports follow [SECURITY.md](SECURITY.md). Support is provided on a best-effort basis with
no response-time guarantee. Commercial support may be discussed at the same email address, but
support, contact, or payment is not required to use the software commercially under Apache License
2.0.
