# Understanding context-efficiency findings

ACL550–ACL558 turn the linter's resolved context measurements into reviewable diagnostics. They are
not generic writing advice and they do not say that shorter context is equally useful.

Warnings identify a resolved profile budget overrun, a measured exact-duplicate threshold, or an
invalid cross-tokenizer comparison. Informational findings identify a fully projected scope or
consolidation opportunity, resolved import amplification, low measured instruction density, or a
high-impact projection that remains static and unvalidated for task quality.

Each finding names its evidence state, token values, affected client profiles and targets, and any
estimate/sample/score caveat. Open its related locations before acting. Suggestions are manual
review steps: F14 supplies no automatic fix and never labels content unnecessary.

For ACL553 and ACL555, check every displayed before/after target. An intended scope target has a
byte-identical assembly proof; a consolidation target retains the same unique content identities.
Those proofs establish only the stated static projection. They do not establish semantic
equivalence, target necessity, instruction quality, or task-quality preservation.

ACL558 exists specifically to preserve that distinction. Evaluate representative tasks separately
before making any empirical quality claim.
