# ACL400–ACL406 security boundary

F11 consumes untrusted repository-derived B03 data but has no repository, filesystem, process,
environment, dynamic-loader, model, callback, or network capability. F02 lexes command text without
expansion or execution. C10/B03 supplies import classifications without allowing F11 to fetch a
remote source.

## Controls

- Closed descriptors reject proxies, accessors, symbols, sparse arrays, duplicates, unknown fields,
  invalid relationships, and limits outside hard ceilings.
- Credential patterns are a reviewed finite set of distinctive prefixes/private-key armor. The
  evaluator returns only a constant diagnostic and hashed semantic discriminator.
- Match text, command arguments, URLs, and source bytes are absent from successful and failed output.
- Dynamic/malformed/ambiguous command evidence produces sanitized uncertainty and cannot create an
  alarming default finding.
- Destructive, secret-access, control-disable, and transmission rules require affirmative lexical
  evidence and exclude explicit prohibitions or safety qualifiers.
- Mutable remote imports warn from existing B03 evidence only; no DNS, HTTP, Git, package, or model
  operation is available.
- B08 suppression matching accepts only parser-issued identity and exact source/line/rule scope.
- B04 validation precedes return. Stylish, JSON, and SARIF apply the centralized B05 redactor.

The canary suite replaces `fetch`, installs an execution marker, supplies executable-looking text,
and proves neither is invoked. The credential corpus snapshots the evaluation plus every formatter
and asserts the exact synthetic token is absent. Resource failures and dependency failures return
fixed messages with fixed paths and do not reflect hostile input.

## Residual risk

Static patterns cannot establish whether a token is active, whether an instruction will be followed,
or whether a command is exploitable. Provider formats and shell behavior evolve. V1 deliberately
prefers missed ambiguous cases over false accusations, and the result must not be represented as a
complete secret scan, malware analysis, sandbox, policy proof, or permission to execute content.

Source locations retain canonical B03 paths. A credential-shaped filename therefore remains inside
the internal diagnostic bundle until B05 formats it; every external sink must use the centralized
sanitizer. A consumer that bypasses the supported formatters owns that additional sensitive-data
boundary.
